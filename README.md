# Stok Takip ve Yönetim Sistemi

Bu proje, işletmelerin envanter süreçlerini dijitalleştirmek ve stok hareketlerini gerçek zamanlı olarak izlemek amacıyla geliştirilmiş bir **Python** tabanlı web uygulamasıdır.

## 🚀 Özellikler

* **Ürün Yönetimi:** Stoktaki ürünleri ekleme, güncelleme ve silme işlemleri.
* **Hızlı Takip:** Ürün miktarlarının ve kritik stok seviyelerinin anlık izlenmesi.
* **Kullanıcı Dostu Arayüz:** Sade ve etkili bir yönetim paneli deneyimi.
* **Veri Yönetimi:** Envanter bilgilerinin güvenli ve düzenli bir şekilde saklanması.

## 🛠️ Kullanılan Teknolojiler

* **Backend:** Python (Flask/Django mimarisine uygun yapı)
* **Frontend:** HTML5, CSS3
* **Versiyon Kontrolü:** Git & GitHub

## 📂 Dosya Yapısı

* `app.py`: Uygulamanın ana mantığını ve sunucu tarafı işlemlerini barındıran temel dosya.
* `.gitignore`: Gereksiz dosyaların (loglar, sanal ortamlar vb.) repoya eklenmesini önleyen yapılandırma.
* `.gitattributes`: Dosya özelliklerini tanımlayan yapılandırma.
